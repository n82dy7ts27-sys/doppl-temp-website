# V1 — DOPPL TEMP WEBSITE

Initial packaged release of the DOPPL generative AI production studio website.

- Responsive company website with Studio, How we work, Capabilities, Our work and Contact sections.
- Looping opening film and transparent animated mascot, including Safari and WebM formats.
- Four expandable capability cards in a two-column desktop grid with a mobile stack.
- Spatial navigation, subtle optical backgrounds and cursor echo.
- Centralised website copy and an optional Word copy handoff utility.
- Password-protected hosting Worker, private media storage integration and authentication checks.
- Application source, bundled media, dependency lockfile and setup documentation.

Built with Next.js, React, TypeScript, custom CSS and Motion. The Our work section is prepared for approved case studies. The release includes no production secret values.
